# Security Policy

Owner: Helton Trindade  
GitHub: @heltonlimatrindade  
Organization: MyWorkOps  
Classification: Commercial Asset Readiness Platform

## Reporting

Report security concerns directly through private channels. Do not open public issues containing sensitive credentials, financial models, customer leads, or private operational data.

## Data Handling

- Do not commit customer or lead personal identifiable information (PII).
- Do not commit production API keys, database credentials, or private payment tokens.
- All pricing models and financial data must be sanitized before publishing public artifacts.

## Supported Scope

Security support applies to the active `main` branch.
